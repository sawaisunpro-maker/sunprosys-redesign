# sunprosys-redesign

株式会社サンプロシステム コーポレートサイト リデザイン案。

## 概要

[sunprosys.co.jp](https://sunprosys.co.jp/) のホームページをモダン・トレンド感のあるデザインにリデザインしたシングルページHTML。

## 特徴

- ダーク × ゴールドのインダストリアル・モダンデザイン
- 公式画像・ロゴをそのまま使用
- ヒーロー4枚自動スライド + パーティクルアニメーション
- カスタムカーソル / スクロール進捗バー
- スクロール連動フェードイン / クリップ画像リビール
- カウンターアニメーション
- パーallax背景
- 横スクロール対応カード
- 完全レスポンシブ

## 含まれる情報

- 企業理念・事業内容（機械設計／制御設計／開発設備）
- 数字インフォグラフィックス（創業年・従業員・資本金・ISO）
- ロボット教室（3コース）
- 会社概要（代表者・設立・資本金・住所等）
- グループ企業（タイトウ工業／アイエスティ）
- 広島ドラゴンフライズ ゴールドパートナー
- ニュース / 採用 / お問い合わせ

## 起動

ブラウザで `index.html` を開くだけ。

```
start index.html
```

## ライセンス

社内検討用。画像・ロゴは sunprosys.co.jp のものを参照しています。
