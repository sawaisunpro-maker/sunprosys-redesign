ROBOT SCHOOLロボット教室

Concept

"好きは才能！"

サンプロシステムでは、児童向けに「思考力」「洞察力」「積極性」を育成する教室を展開。 遊びながら、考える力・観察する力・創造する力を育みます。 初心者向けの体験授業もご用意しています。

🧠

思考力

論理的に考え、問題を解決する力を養います

👀

洞察力

本質を見抜き、応用する観察力を育てます

🚀

積極性

挑戦し、表現する積極的な姿勢を育成

01

Course 01

ロボット教室

幼稚園〜対象

ブロックを使い、自分のイメージをカタチにし、モノを生み出すことで想像力や感性を育成します。 ロボットとモーターの組み合わせで、楽しみながらロボット製作の基礎を学びます。

✓
遊びながら学ぶブロック遊びの延長で、自然と仕組みを理解。
✓
想像力を育むイメージをカタチにする経験を積み重ねます。
✓
モーター制御ロボット+モーターの組み合わせを実体験。
🤖
02

Course 02

こどもプログラミング教室

小学1年生〜対象

パソコンアプリを使用してゲーム製作に挑戦。 「考える力」「論理的思考」を段階的に育てる学習プログラムです。

✓
ゲーム製作身近なゲームを自分で作る楽しさを体験。
✓
論理的思考順序立てて考える力を自然に身につけます。
✓
段階的学習レベルに合わせてステップアップ。
💻
03

Course 03

ロボティクス
プロフェッサー教室

小学6年生〜対象

C言語によるプログラミングでロボットを制御。 ロボット工学、物理、数学、プログラミング、アルゴリズムまで幅広く本格的に学べる上級コースです。

✓
C言語実践本格的なプログラミング言語に挑戦。
✓
多分野学習ロボット工学・物理・数学・アルゴリズム。
✓
未来エンジニア将来のエンジニアに必要な力を育成。
🔬
